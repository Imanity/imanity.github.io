# 项目进度

> 依据当前仓库代码整理，更新于 2026-10-19。

## 当前阶段

项目已完成可构建、可部署的个人主页骨架，以及可分批维护的多图库数据链路。云南图库已迁入新的 JSON 与 i18n 词表结构。

## 待完善

### 优先级高

- 首页组件目前为空，需要补充首屏介绍、主要入口或代表内容。
- 地图筛选已接入 Google Maps 底图和缩放；大量地点的标记聚合尚未实现。
- 本站依赖相邻目录中的图库源码；需要发布并改用稳定版本，或明确长期采用多仓库联动方式。

### 优先级中

- 项目卡片缺少仓库地址、演示地址、时间等可继续浏览的信息。
- 照片已有详情页，但没有灯箱、分页或虚拟化，大规模照片库的体验尚未验证。
- 页面标题区的简介为空，`profile.focus` 也尚未填充。
- 缺少组件、筛选逻辑和路由的自动化测试。

### 优先级低

- 补充更完整的 SEO 和分享元数据。
- 增加 lint、格式化检查及构建产物体积监控。
- 根据实际访问设备继续检查无障碍和移动端体验。

## 建议的下一步

1. 完成首页内容，形成清晰的个人主页入口。
2. 根据照片规模决定是否增加地图标记聚合和照片预览气泡。
3. 为 `tabi-gallery` 补测试并发布首个稳定可消费版本。
4. 扩充项目字段与照片浏览体验。
